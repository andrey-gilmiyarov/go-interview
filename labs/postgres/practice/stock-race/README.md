# Последний товар

## Условие

Два запроса одновременно покупают единственную единицу. Наивный код читает stock, проверяет его в Go и записывает stock-1. Оба запроса возвращают успех.

Реализуйте Buy(ctx, pool, product, quantity). Создание заказа и списание должны иметь общий исход. При недостаточном остатке верните ops.ErrStock; не допускайте нулевое или отрицательное количество.

## Работа

Из каталога лаборатории после `./lab.sh up`:

```sh
./lab.sh run stock-race
go test -tags=exercise ./practice/stock-race/starter
go test -tags=integration ./practice/stock-race/solution
```

Откройте starter в IDE. Не меняйте контракт функции и общие проверки. Условие использует схему сценария, подготовленную тестом; не запускайте несколько проверок этого ID одновременно.
