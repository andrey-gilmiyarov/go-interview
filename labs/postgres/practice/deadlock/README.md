# Найти цикл ожидания

## Условие

A меняет товар 1, B — товар 2. Затем A просит товар 2, а B — товар 1. Одна операция получает ошибку.

Нарисуйте граф ожиданий, найдите blocking PID, назовите SQLSTATE и исправьте порядок. Объясните, можно ли заранее назвать транзакцию-жертву.

## Работа

Из каталога лаборатории после `./lab.sh up`:

```sh
./lab.sh run deadlock
```

Для ручного воспроизведения используйте `schedule.sql` в каталоге задачи: выполняйте отмеченные шаги в отдельных psql-сессиях. Это расписание, а не файл для запуска целиком.

<details><summary>Подсказка</summary>

Наличие двух ожиданий ещё не означает цикл. Проследите владельца каждого ресурса.

</details>
