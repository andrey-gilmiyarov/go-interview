# Восстановление задания после сбоя

## Условие

Два worker выбирают задания. Один выполняет эффект, теряет связь и позднее пытается подтвердить работу, которую уже перехватил другой worker.

Реализуйте Claim и Ack. Claim не ждёт занятую строку, выдаёт lease и возрастающий token. Ack разрешён только текущей попытке с действующим lease. Истёкшая работа доступна повторно.

## Работа

Из каталога лаборатории после `./lab.sh up`:

```sh
./lab.sh run job-queue
go test -tags=exercise ./practice/job-queue/starter
go test -tags=integration ./practice/job-queue/solution
```

Откройте starter в IDE. Не меняйте контракт функции и общие проверки. Условие использует схему сценария, подготовленную тестом; не запускайте несколько проверок этого ID одновременно.
