# Что увидят две транзакции

## Условие

В двух строках products хранится по единице. Правило: хотя бы на одном складе товар должен остаться. Две сессии читают сумму, затем каждая убирает товар только из своей строки.

Предскажите результаты Read Committed, Repeatable Read и Serializable. Назовите, что нужно повторить после 40001. Объясните, в какой момент возникает snapshot Repeatable Read.

## Работа

Из каталога лаборатории после `./lab.sh up`:

```sh
./lab.sh run isolation
```

Для ручного воспроизведения используйте `schedule.sql` в каталоге задачи: выполняйте отмеченные шаги в отдельных psql-сессиях. Это расписание, а не файл для запуска целиком.
