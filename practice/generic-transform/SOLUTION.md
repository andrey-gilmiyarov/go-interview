# Разбор: generic-transform

Transform сохраняет nil-вход как nil и выделяет результат той же длины для ненулевого среза. Индексный цикл сохраняет порядок даже если callback создаёт новый тип результата.

Ограничение any намеренно широкое: алгоритм не сравнивает T или R, не использует значения как ключи map и не требует арифметики. Более узкое ограничение не выражало бы реального требования API.
