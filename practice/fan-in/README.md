# Объединение потоков

## Условие

Реализуйте <code>starter.Merge</code>, чтобы читать из нескольких входов и передавать значения в общий канал.

~~~go
func Merge(ctx context.Context, inputs ...<-chan int) <-chan int
~~~

## Контракт

Порядок значений каждого отдельного входа сохраняется; общий порядок между входами не определён. Nil-входы игнорируются. Выход закрывается, когда закончились все входы или отменён контекст; без входов он закрывается сразу. Если контекст уже отменён до вызова, output возвращается закрытым, не читая input. При одновременной готовности отмены и отправки <code>select</code> может передать уже готовое значение: отмена не имеет приоритета. Входы принадлежат вызывающей стороне и не закрываются функцией. Потребитель, прекративший чтение, должен отменить контекст.

Проверка вашей реализации: <code>go test -tags exercise ./practice/fan-in/starter</code>. Она запускает общие проверки с кодом в starter. Эталонная реализация: <code>go test ./practice/fan-in/solution</code>.

<details><summary>Подсказка</summary>

Каждому входному каналу нужен собственный читатель, а закрытие общего канала должно происходить после завершения всех читателей.

</details>
