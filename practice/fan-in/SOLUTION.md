# Разбор: fan-in

Если контекст уже отменён, Merge сразу возвращает закрытый output и не запускает читателей. Иначе по одному goroutine читает каждый ненулевой вход. Отправка в общий канал и ожидание следующего элемента учитывают контекст. WaitGroup позволяет закрыть выход только после завершения всех читателей. При пустом наборе входов закрываем выход сразу.

После начала работы select не даёт отмене приоритет: если одновременно готовы отправка и отмена, значение может быть передано. Если потребитель прекращает чтение, он обязан отменить контекст, иначе отправитель может ждать.
