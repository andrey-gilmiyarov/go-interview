# Разбор: pipeline

Если контекст отменён до вызова, функция синхронно закрывает выход и не читает вход. Иначе этап выполняет контекстно-зависимый select и при чтении, и при отправке. Отмена поэтому завершает как ожидание нового значения, так и отправку результата потребителю, который больше не читает. Только output закрывается функцией этапа: закрывать вход обязан его владелец.

При одновременной готовности отмены и отправки select вправе выбрать любую готовую ветку; отмена не имеет приоритета. Если потребитель перестал читать, он должен отменить контекст, иначе этап может ждать отправки.
