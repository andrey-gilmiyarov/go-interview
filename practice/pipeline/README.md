# Этап pipeline, возводящий в квадрат

## Условие

Реализуйте <code>starter.Square</code>. Один этап читает числа из входного канала, отправляет их квадраты и закрывает выход после закрытия входа или отмены контекста.

~~~go
func Square(ctx context.Context, in <-chan int) <-chan int
~~~

<<< @/../practice/pipeline/example/example.go

## Контракт

Чтение из входа и отправка в выход должны учитывать контекст. Если контекст уже отменён до вызова, output возвращается закрытым и input не читается. Если отправка и отмена становятся готовы одновременно, <code>select</code> может выбрать отправку; отмена не имеет приоритета и уже готовое значение может быть передано. Input принадлежит вызывающей стороне и не закрывается этапом. Если потребитель перестал читать, он должен сам отменить контекст.

Проверка вашей реализации: <code>go test -tags exercise ./practice/pipeline/starter</code>. Она запускает общие проверки с кодом в starter. Эталонная реализация: <code>go test ./practice/pipeline/solution</code>.

<details><summary>Подсказка</summary>

Одна проверка контекста перед циклом не разблокирует отправку, которая уже ждёт получателя.

</details>
