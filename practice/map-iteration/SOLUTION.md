# Разбор: map-iteration

Для существующих и не удалённых ключей проверяется один обход каждого ключа, но порядок не сравнивается. Спецификация допускает появление или пропуск вставленного ключа и исключает ключ, удалённый до его посещения. Наблюдение одного запуска не устанавливает гарантию.

Проверка запускает этот Predict и отдельно выполняет канонический пример из contract.
