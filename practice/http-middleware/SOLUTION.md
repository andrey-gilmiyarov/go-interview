# Разбор: http-middleware

Handler фиксирует снимок пользовательской map при создании, чтобы вызывающий код не мог незаметно изменить данные уже запущенного обработчика. Авторизация выполняется до метода и пути: неавторизованный запрос получает один ответ независимо от того, существует ли пользователь или маршрут.

Путь принимается только в форме <code>/users/&lt;id&gt;</code> без дополнительных сегментов. Метод GET возвращает JSON, остальные методы получают 405 вместе с Allow. Пустой секрет не имеет безопасной интерпретации, поэтому конструктор явно останавливается с panic.
