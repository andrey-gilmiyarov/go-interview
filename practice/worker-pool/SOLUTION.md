# Разбор: worker-pool

Канал заданий передаёт индексы, а каждый worker записывает свой результат в отдельную ячейку. Так сохраняется порядок без общей блокировки для записи результатов. Количество worker goroutine ограничено минимумом из параметра workers и длины входа.

Ошибка callback отменяет общий рабочий контекст. Producer перестаёт выдавать задания, а функция ждёт группу worker-ов, прежде чем вернуть первую замеченную ошибку. Родительская отмена проходит в те же callback-и. Эта гарантия предполагает, что callback соблюдает контекст; остановить функцию, которая игнорирует контекст извне нельзя.
