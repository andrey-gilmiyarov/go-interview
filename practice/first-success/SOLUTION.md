# Разбор: first-success

Общий дочерний контекст позволяет отменить оставшиеся попытки после первого принятого успеха. Mutex защищает выбор победителя; индексированный список сохраняет ошибки отдельных jobs без блокировки. После WaitGroup функция возвращает выбранный результат, ошибку родителя или errors.Join всех ошибок.

Ошибку остановки нельзя навязать функции, которая игнорирует контекст. Первый успех означает первый успех, который функция приняла; порядок запуска goroutine и глобальный порядок результатов не обещаются.
