# Разбор: errgroup-batch

SetLimit задаёт верхнюю границу активных callbacks, а WithContext отменяет общий дочерний контекст при первой ошибке. Перед вызовом пользовательской функции wrapper проверяет этот контекст: jobs, очередь которых освободилась уже после отмены, не вызывают callback. Wait дожидается запущенных функций и возвращает первую ошибку группы; если ошибок группы не было, отдельно возвращается ошибка родительского контекста.

Контекст не может принудительно остановить callback, который его игнорирует. Limit должен быть положительным, в том числе для пустого списка.
