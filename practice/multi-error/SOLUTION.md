# Разбор: multi-error

Проверка проходит по всем значениям и создаёт отдельную ошибку для каждого отрицательного значения. ItemError хранит индекс и значение, а Unwrap связывает конкретное нарушение с общим sentinel. errors.Join сохраняет все причины, поэтому вызывающий код может применять и errors.Is, и errors.As.

Нельзя возвращать nil slice пользовательского типа как значение error: после преобразования в интерфейс он будет ненулевым. Эталон собирает ошибки в []error и возвращает errors.Join только после обхода.
