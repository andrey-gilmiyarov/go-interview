# Карта миграции старых языковых примеров

Сценарии перенесены в проверяемые упражнения и в компилируемый пакет examples/language. Код, который раньше печатал адреса, ёмкости или зависимый от планировщика порядок, заменён на наблюдаемые свойства языка. Новые тесты сравнивают значения и гарантии, а не конкретные адреса или вероятностные исходы.

| Старый источник | Замена | Сохранённый механизм и исправление |
| --- | --- | --- |
| arrays_and_slices/empty_and_nil_slices/main.go | [nil-empty-json](../../practice/nil-empty-json/README.md) | Сохранено различие nil и пустого среза; дополнительно проверяется JSON v1. Убраны архитектурное утверждение о размере заголовка и вывод адресов через unsafe.SliceData. |
| arrays_and_slices/bad_append/main.go | [slice_examples.go](../../examples/language/slice_examples.go) | Два случая append при свободной и нулевой ёмкости. Тест показывает, что заголовок вызывающего кода не удлиняется, а запись в общий массив может стать видна после reslice. |
| arrays_and_slices/range_by_slice/main.go | [range_mutation.go](../../examples/language/range_mutation.go) и [range-mutation](../../practice/range-mutation/README.md) | Сохранён исходный цикл с записью, append и повторной записью. Тест отделяет длину обхода range от изменений заголовка x; комментарий о «копии x» заменён точной проверяемой моделью. |
| arrays_and_slices/slice-structs/main.go | [slice_layout.go](../../examples/language/slice_layout.go) | Сохранены array-of-structs и struct-of-slices формы для суммирования. Код теперь находится в именованном пакете, который проходит go test. |
| arrays_and_slices/slice-structs/main_test.go | [slice_layout_bench_test.go](../../examples/language/slice_layout_bench_test.go) | Сохранено сравнение layout в benchmark. Подготовка данных вынесена за b.Loop, а проверок абсолютной скорости или числа аллокаций нет. |
| arrays_and_slices/slicing task/main.go | [slice_examples.go](../../examples/language/slice_examples.go) | Сохранён повторный append перекрывающихся срезов. Тест проверяет исходный массив после первого изменения и итог нового среза после второго append. |
| arrays_and_slices/slice_with_function/main.go | [slice_examples.go](../../examples/language/slice_examples.go) | Сохранены изменение элемента, append в функции без возврата среза и reslice в вызывающем коде. Раздельные снимки показывают общий массив и отдельный заголовок. |
| defer/functions/mian.go | [defer_examples.go](../../examples/language/defer_examples.go) | Сохранены немедленное вычисление аргумента get, обычная инструкция между вызовами и отложенный вызов handle. Опечатка mian.go исчезла вместе со старым деревом. |
| defer/order/main.go | [defer_examples.go](../../examples/language/defer_examples.go) | Сохранены плоский LIFO-порядок и вложенные defer. Тест проверяет последовательности без побочного вывода из main. |
| defer/receiver/main.go | [defer_examples.go](../../examples/language/defer_examples.go) | Сохранены value receiver и pointer receiver. Проверка подтверждает копирование значения при регистрации и чтение объекта по указателю при выполнении. |
| errors/error-method/main.go | [user_error.go](../../examples/language/user_error.go) и [typed-nil](../../practice/typed-nil/README.md) | Сохранён UserError с pointer receiver Error и сообщением о пользователе. Отдельный typed-nil пример проверяет интерфейс без вызова метода на nil-указателе. |
| interfaces/not_nil/main.go | [typed-nil](../../practice/typed-nil/README.md) и [user_error.go](../../examples/language/user_error.go) | Сохранено различие между nil concrete pointer и error-интерфейсом. Удалён ReadFile stub, который возвращал typed nil PathError даже при успешной ветке и не читал файл. |
| concurrency/select-behavior/main.go | [select_drain.go](../../examples/language/select_drain.go) и [select-states](../../practice/select-states/README.md) | Сохранены ранний выход и drain после сигнала. Исправленный путь ждёт готовые сообщения без time.Sleep и проверяется при заранее заполненных каналах; порядок выбора не угадывается. |
| test/selectbehavior/select-behavior.go | [select_drain.go](../../examples/language/select_drain.go) и [select-states](../../practice/select-states/README.md) | Сохранены BadListing и GoodListing сценарии как StopWithoutDraining и DrainOnDisconnect. Удалены Sleep вместо синхронизации и отсутствие join; тест проверяет полное чтение очереди. |

Старые файлы удалены только после того, как соответствующие reference tests стали проходить. Канонические prediction-примеры находятся в practice/*/contract/example.go; заглушки проверяются только с exercise build tag, а обычный go test запускает проверенные решения.
